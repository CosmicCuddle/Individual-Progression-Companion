This intentionally limits Refresh in the exceptional ambiguous case; Information/owner review required. Old-server/no-push named-self retry behavior remains unchanged, including pre-existing delayed same-name reply ambiguity. Server-ordered push delivery and legacy sender format need native proof; a local addon able to send same-self addon messages is not a security boundary.
