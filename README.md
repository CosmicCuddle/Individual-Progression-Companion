Individual Progression Addon - Server Companion v5.0

Install:
Copy the IndividualProgressionAddon folder into Interface\AddOns and replace the previous version.

Main Addon Commands:
/ip                 Toggle the guide
/ip current         Open your current progression stage
/ip wrath           Open the Wrath overview
/ip wrathdungeons   Open Wrath dungeon / Heroic guidance
/ip wrathemblems    Open Wrath emblem / Dalaran quest guidance
/ip wrathreps       Open Wrath reputation guidance
/ip wrathprofessions Open Wrath profession guidance
/ip wrathpvp        Open Wrath PvP guidance
/ip wintergrasp     Open Wintergrasp / Vault guidance
/ip tournament      Open Argent Tournament guidance
/ip commands        Open the full addon + IP server command reference
/ip refresh         Refresh progression from the server
/ip help            Show addon commands in chat
